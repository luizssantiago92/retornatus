# Glossary

| Term | Meaning |
| --- | --- |
| **Action** | Bounded work unit under a Change |
| **Assurance** | Verdict over Claims given Evidence |
| **Authority** | Who may authorize an effect (DELEGATED, HUMAN, …) |
| **Boundary** | Scope constraint (often advisory to the host) |
| **Bypass** | Governed skip of a gate with durable record |
| **Change** | Durable governed unit of work (`C-xxxx`) |
| **Claim** | Statement that must be established |
| **Contract** | Authoritative WHAT + constraints + DONE |
| **Demand** | Intent that opens a Change |
| **Decision** | Human boundary artifact |
| **Evidence** | Attributable observation, ideally Claim-bound |
| **Finding** | Relevant observation |
| **Gate** | Mechanical check; non-zero = STOP |
| **Hub skill** | Progressive disclosure skill teaching the loop |
| **Learning** | Validated experience (informs, does not constrain alone) |
| **Memory** | Durable engineering continuity |
| **Policy** | ALLOW / DENY / REQUIRE_HUMAN evaluation |
| **Question** | Structured uncertainty grounded in Findings |
| **Resolution** | Established outcome of a Question |
| **Rule** | Active authoritative constraint |
| **Runtime** | Disposable operational data |
| **Situation** | Understanding sufficient for a Contract |
| **Skill** | On-demand specialization procedure |
| **Status** | Derived projection of progress |
| **Task** | Optional decomposition inside an Action |
| **Wake** | Reconstruct continuity from repository state |

Retornatus

Govern the work.
Bound the agent.
Verify the outcome.

A repo-native governance harness for AI coding agents — Contracts before code, gates that stop false “done”, and Evidence that lives in git.

Install Quick start

Without it / with it

Without

  • Jumps to code and says “done”
  • Each chat starts from zero
  • Stale skill packs for every stack

With Retornatus

  • Active Contract + DONE criteria first
  • .retornatus/ survives sessions
  • One Skill researched now for this Change

Four pillars

Contract

WHAT, constraints, and DONE before build.

Gates & Assurance

Non-zero exit = STOP. Claim-bound Evidence → verdict.

Memory

Files + wake beat chat scrollback.

On-demand Skills

Research current sources — no rotting packs.

How work moves

Demand → Situation → Contract → Action
       → Skill? → Execution (host) → Evidence → Assurance
       → Learning / Skill evolution → return informed

Your host executes. Retornatus governs and records.

Install

uv tool install retornatus
cd /path/to/your-app
retornatus init
retornatus integrate
retornatus doctor

Python 3.11+ · uv recommended · then open the project in your AI coding agent.

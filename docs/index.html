Retornatus

Keep AI coding agents honest — with goals, memory, and proof.

Install once in your project. Your agent works toward a clear outcome, remembers across chats, and cannot call work “done” without evidence you can see.

Install Quick start

Why people use it

  • You stay in control. The agent proposes and builds; you keep the bar for “done.”
  • Chat stops being the only memory. Intent and progress live in the repo, so the next session (or teammate) can continue.
  • Fewer false finishes. Work closes when there is proof — not when the model sounds confident.
  • Right amount of ceremony. Tiny fixes stay light; risky work earns more structure.
  • Skills when you need them. Specialize for the problem at hand — with current research and your confirmation before a Skill is created.

How you use it

  1. Install the CLI and initialize it in your project.
  2. Open the project in Cursor, Claude Code, Codex, or your preferred agent.
  3. Describe what you want — Retornatus clarifies requirements, stages intake when needed, and agrees a finish line before the build sprint.
  4. Let the agent work under that agreement; check status anytime.
  5. Close when evidence matches the goal — then the next return starts wiser.

Your coding agent still writes the code. Retornatus governs the loop and keeps the record. Deep mechanics live in the docs.

The idea in one breath

Govern the work. Bound the agent. Verify the outcome. Demand what you need, agree on what “done” means, execute, then verify with proof that stays in git — so every return to the project is informed, not amnesiac.

Without

  • Jumps to code and declares victory
  • Each chat starts from zero
  • You rediscover the same mistakes

With Retornatus

  • Clear finish line before the build sprint
  • Project memory survives the tab
  • Proof required before “done”

Presets

retornatus init --preset writes a starting config from a file shipped in the package. verify checks that the named commands ran and exited 0. It does not grade the tests, the deploy plan, or the eval set.

python

Python 3.11+ tests and static checks: pytest, ruff, and mypy.

python-platform

Extends python. Ship and AI rules run when deploy files or model paths change.

fastapi

Extends python-platform. API layout globs. Alembic paths count as ship.

django

Extends python-platform. Django layout globs. Migration paths count as ship.

rag

Extends python-platform. Retrieval and prompt globs, with a stronger AI surface.

worker

Extends python-platform. Task and queue globs. Task code counts as ship and needs a retry note.

retornatus init --list-presets
retornatus init --preset fastapi

Ship means Docker, Compose, Terraform, Helm, or a workflow file. With worker, task, schedule, and queue files count as ship too. AI means prompts, evals, MCP, or retrieval code. If those paths are not in the Change, the extra rule is not required. An existing config stays put unless you pass --force-config. Presets guide.

Install

uv tool install retornatus
cd /path/to/your-app
retornatus init
retornatus integrate
retornatus doctor

Needs Python 3.11+ · uv recommended · also on PyPI. Then open the project in your AI coding agent and start a change. On a pull request, the GitHub Action posts one sticky verdict comment. integrate --hooks can inject the active Change at session start and keep the turn open until that Change is SATISFIED. That hook is a guardrail. The pull-request check stays the source of truth. Agent hooks.

What’s new

Highlights from 1.9.1, including the subagent-stop hook, the scope warning hook, the SessionStart hook, agent hooks, and init presets.

  • Subagent-stop hook — retornatus hook subagent-stop reminds a Cursor, Claude Code, or Codex subagent when the active Change is not SATISFIED. [hooks] subagent_stop defaults to true.
  • Scope warning hook — retornatus hook file-edit warns when an edit leaves the active Change scope. [hooks] scope_mode is warn, block, or off.
  • SessionStart hook — retornatus hook session-start injects the active Change when a Claude Code, Cursor, or Codex session starts. integrate --hooks installs it beside the Stop hook.
  • Agent hooks — opt-in Stop hook via retornatus hook stop and integrate --hooks for Claude Code, Cursor, and Codex. The turn stays open until the active Change is SATISFIED. CI stays the source of truth.
  • Init presets — python, python-platform, fastapi, django, rag, and worker. Ship and AI rules run only when those paths change, and they check that the command ran.
  • Verify receipts — Ed25519 signature from verify --receipt; anyone can check it with the committed public key (receipt verify). The private key stays outside the repo.
  • Attempt budgets — cap Action retries with action budget / gate budget.
  • Prompt intake — stage a freeform ask; Skills only after you confirm CREATE=yes.
  • Situation as requirements — focused questions before the Contract.
  • Mascot — chrome agent in a black suit, teal ouroboros, orange comet flame. The hero uses the same rounded card as the README.
